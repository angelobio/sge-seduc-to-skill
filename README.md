# SGE SEDUC-TO: skill de lançamentos

Skill para Claude que orienta o lançamento no SGE da SEDUC-TO (Tocantins): frequência diária, conteúdo aplicado e planejamento das eletivas (ementa e plano de aula mensal).

## Como usar

- Claude Cowork ou Claude Code: copie a pasta `sge-seduc-to-lancamentos` para a pasta de skills, ou carregue o arquivo do skill.
- Login é sempre do professor. A skill não recebe senha.
